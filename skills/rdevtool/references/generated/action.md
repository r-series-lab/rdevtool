## `rdevtool action`

Inspect, validate, and run parameterized resource Actions

```text
Inspect, validate, and run parameterized resource Actions

Usage: rdevtool action [OPTIONS] <COMMAND>

Commands:
  path       Print the resolved Action config path
  list       List configured Actions
  show       Show one resolved Action, including runner and parameters
  validate   Validate the full Action config or one Action key
  plan       Generate and persist a trusted plan for a plan/apply Action
  plan-show  Show a persisted Action plan without executing it
  apply      Apply one unexpired, unconsumed Action plan
  run        Validate parameters and run an Action
  help       Print this message or the help of the given subcommand(s)

Options:
      --source <SOURCE>
          Resource config source ID or workspace key

      --file <PATH>
          Use an Action config file directly instead of a managed config source

      --json


  -h, --help
          Print help
```
