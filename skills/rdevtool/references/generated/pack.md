## `rdevtool pack`

Export, inspect, plan, apply, and roll back portable configuration packs

```text
Export, inspect, plan, apply, and roll back portable configuration packs

Usage: rdevtool pack [OPTIONS] <COMMAND>

Commands:
  inventory    List projects, workspaces, and configuration sources available for export
  export       Export selected configuration modules to a portable .rdtpack archive
  inspect      Validate a .rdtpack archive and show its manifest and contents
  import-plan  Resolve mappings and conflicts, then persist an import plan
  import-run   Apply a previously persisted import plan after revalidating its inputs
  rollback     Restore every file changed by a completed import transaction
  help         Print this message or the help of the given subcommand(s)

Options:
      --json


  -h, --help
          Print help
```
