# Security Policy / 安全政策

## Supported versions / 支持范围

Only the latest `0.1.x` Public Preview is maintained. Unsigned local builds and historical Releases are not supported distribution packages.

当前仅维护最新的 `0.1.x` Public Preview。未签名的本地构建和历史 Release 不属于正式支持的分发包。

## Private reporting / 私下报告

Use **Security > Report a vulnerability** in this GitHub repository. Include the affected version, operating system, reproduction conditions, and impact. Do not place credentials, internal URLs, authentication responses, private repository paths, or directly exploitable details in a public Issue.

请使用 GitHub 仓库 **Security > Report a vulnerability** 私下报告，并附上受影响版本、操作系统、复现条件和影响范围。不要在公开 Issue 中粘贴凭据、内部 URL、认证响应、私有仓库路径或可直接利用的细节。
