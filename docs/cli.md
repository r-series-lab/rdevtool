# `rdevtool`

A local development workbench for projects, runtimes, builds, and agents.

```text
A local development workbench for projects, runtimes, builds, and agents.

Usage: rdevtool [OPTIONS] <COMMAND>

Commands:
  desktop         Open the native desktop workbench
  info            Show executable identity, paths, active workspace, and credential presence
  capabilities    Publish machine-readable CLI features and structured command metadata
  doctor          Inspect configuration, workspace, runtime, storage, and installation health
  docs            Generate CLI reference documentation from the current command definitions
  app             Read and update application preferences
  workspace       Manage global, scoped, and demand workspaces
  projects        Inspect and configure projects, targets, and debug profiles
  tui             Open the terminal user interface
  build           Plan, run, follow, and inspect builds
  git             Inspect repositories and run controlled Git workflows
  migrate-config  Migrate legacy project configuration into the current schema
  navigation      Search and manage workspace resource entry points
  link            Inspect and run reusable local debugging chains
  config-source   Compare, copy, and select workspace configuration sources
  pack            Export, inspect, plan, apply, and roll back portable configuration packs
  action          Inspect, validate, and run parameterized resource Actions
  proxy           Configure and operate local proxy profiles and rules
  runtime         Inspect, start, diagnose, and follow project runtimes
  artifacts       Inventory managed files and produce safe cleanup plans
  web-actions     Run registered browser actions against controlled targets
  notes           Search and maintain Markdown project knowledge
  history         Inspect operation history and safely prepare replays
  workflow        Plan and execute composed development workflows
  agent           Expose compact context, capabilities, and Skill compatibility for AI agents
  help            Print this message or the help of the given subcommand(s)

Options:
      --config <CONFIG>
          [env: RDEVTOOL_CONFIG_PATH=]

      --workspace <KEY>
          [env: RDEVTOOL_WORKSPACE_KEY=]

      --json


  -h, --help
          Print help

  -V, --version
          Print version
```
