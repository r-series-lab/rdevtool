# Support / 获取帮助

- 使用说明：[rdt.rurie.top](https://rdt.rurie.top)
- Bug 与功能建议：[GitHub Issues](https://github.com/r-series-lab/rdevtool/issues)
- 安全问题：按 [SECURITY.md](SECURITY.md) 私下报告

提交问题时请提供 rDevTool 版本、操作系统与架构、复现步骤、预期结果和已脱敏的诊断。不要上传 Token、Cookie、认证响应、内部 URL、业务数据或完整私人路径。

For help, start with the [official documentation](https://rdt.rurie.top/en/docs), then use GitHub Issues for reproducible bugs and feature requests. Include the app version, OS and architecture, reproduction steps, expected behavior, and redacted diagnostics. Report vulnerabilities privately through [SECURITY.md](SECURITY.md).
